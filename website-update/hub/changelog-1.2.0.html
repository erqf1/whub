1.2.0 November 2026

Neu

  • Schnellere Downloads: Große Pakete kommen über mehrere Verbindungen gleichzeitig. Bricht eine einzelne Verbindung zu GitHub ein, laufen die anderen weiter – in Tests bis zu fünfmal so schnell. Die Prüfsumme wird danach wie bisher über die ganze Datei gerechnet.
  • Alles automatisch aktualisieren: Auf Wunsch spielt W Hub nach dem Start alle Updates still ein. Programme, die gerade offen sind, werden nicht geschlossen, sondern später nachgeholt. Standardmäßig aus.
  • Mit dem System starten: W Hub wartet ohne Fenster als kleines Symbol im Infobereich, sucht beim Anmelden und alle 6 Stunden nach Updates und gibt Bescheid (oder aktualisiert selbst). Über das Symbol: Öffnen, Nach Updates suchen, Beenden. Das X schließt dann nur das Fenster.

Verbessert

  • Im Hintergrund braucht W Hub nur den Hauptprozess, ohne Oberfläche und ohne Grafikbeschleunigung: rund 170 MB Arbeitsspeicher und im Leerlauf praktisch keine CPU.
  • Ein Klick auf eine Update-Meldung öffnet W Hub direkt bei den Updates, auch wenn noch kein Fenster offen war.
  • Abgebrochene Download-Stücke werden automatisch neu geladen; beim Abbrechen bleiben keine halben Dateien liegen.
